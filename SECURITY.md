# Security Policy

Nivora Browser is pre-alpha (`0.1.0a1`) and has no supported releases yet. See
[docs/SECURITY.md](docs/SECURITY.md) for what is and is not covered.

## Reporting a vulnerability

Please report privately through GitHub's private vulnerability reporting for this repository
(Security tab, "Report a vulnerability"). Do not open a public issue with exploit details, and do
not include passwords, cookies, session tokens or profile files in a report.

If the problem is in Firefox or in Zen Browser and also affects their official builds, it should
be reported to those projects as well:

- Mozilla: https://www.mozilla.org/security/
- Zen Browser: https://github.com/zen-browser/desktop/security
