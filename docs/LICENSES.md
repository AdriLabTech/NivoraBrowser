This is an inventory, not legal advice. It says what Nivora redistributes, under which license, and
what has **not** been verified. Items marked **review** must be settled before the first public
release.

| Component | License | Where | Notes |

| Mozilla Firefox (Gecko, the browser UI, and Mozilla's vendored third-party code) | MPL-2.0 plus the licenses of its bundled components | `engine/` at build time; listed by the running browser at `about:license` | Mozilla's own notices ship with Firefox. | Zen Browser | MPL-2.0 (`../LICENSE`) | the whole tree | Files Nivora modifies keep their notices and stay MPL-2.0 |

MPL-2.0 is file-level copyleft: the source of every MPL file that is modified and distributed must
remain available under MPL-2.0. This repository is that source. A binary distribution must tell
users where to get it (see [DISTRIBUTION.md](DISTRIBUTION.md)).

## 3. Removed because it could not be redistributed

**Nucleo icons.** Zen's `zen-icons/nucleo/` files carried this notice: _"The Nucleo icons are
copyrighted. Redistribution is not permitted. Use in source and binary forms, with or without
modification, is permitted only if you possess a Nucleo license."_ Nivora has no Nucleo license, so
all 154 files were regenerated from Phosphor Icons (`tools/nivora/generate_icons.py`), and a test
fails if an icon in the tree is not from Phosphor. **The unmodified first commit of this repository
still contains the Nucleo files**, exactly as Zen's repository does. Removing them from the history
would mean rewriting the first commit, which would break the "unmodified upstream" guarantee and
upstream merging; the maintainer should decide whether that is wanted.

## 5. Obligations when distributing a binary

1. Keep every copyright and license notice in the files (done in the tree).
2. Ship `LICENSE`, this file and `licenses/` with the package, and Firefox's own `about:license`
   content (the build produces it).
3. Offer the corresponding source: the repository at the tag used, and the exact Firefox version
   named in `surfer.json`.
4. Do not present Nivora as a Mozilla or Zen product; do not use their names or logos as Nivora's.
5. Include the Phosphor, Ionicons, Motion, Junicode and emoji-data notices (section 2).

Not verified: the licenses of everything inside Firefox's `third_party` directories (Mozilla's
responsibility, shown in `about:license`); the licenses of the crates Firefox vendors; whether an
MPL-2.0 header on documentation is what the maintainer wants.
